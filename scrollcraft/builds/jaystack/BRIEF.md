# JayStack portfolio: scroll brief

Interviewed 2026-10-31 (four questions, multiple choice). Answers below are the
user's picks; everything marked *authored* was decided within that direction.

## The eight topics

1. **Vibe:** "Evolve it." Keep the lime + near-black engineering workbench,
   the factory hero and Pip. *Authored references:* a machinist's exploded-view
   drawing, a game's build/loading screen, a code editor's bracket matching.
2. **Journey:** *authored from the existing site order.* Hero (who Jay is and
   what he builds), Work (FungEye, then three projects assembling), About,
   Expertise, Contact.
3. **Energy:** calm open with a live factory, rising to the work, quiet About,
   momentum through the disciplines, a settled close.
4. **Feeling + the one moment:** "Projects assemble." Scrolling into the work,
   the factory builds each project: its layers fly together into the finished card.
5. **Unseen-elsewhere seed:** projects that are built in front of you, with a
   build line that ticks while the parts bolt together.
6. **Range:** premium-minimal, evolved. No departure from the existing palette.
7. **World:** "Distinct scenes." Each section scrolls differently.
8. **Assets:** "Code-built layers." No generation, no spend. Existing factory
   scene, project art and FungEye screenshots only.

## Grammar

**Workbench stations** (new). Each section is a station on a production line.
Nav stays the existing header (wordmark + three anchors + "Let's talk"). The
hero is a live machine already running; the close is a work order (the contact
form) on paper. Bans: `scrub` video, continuous drift, section counters, a
scroll cue, more than one pinned act per section.

Why not the eight defined grammars: filmic one-shot and continuous world need a
single world (user chose scenes); live surface bans the display headings the
site already owns; typographic poster and editorial would discard the factory;
gallery is too flat for "assemble"; split stage has no two-sided argument here;
rhythmic cutlist bans `pin`, which the peak needs.

you." Lives in Work. Largest span (300vh pinned on desktop).

**Tell-someone sentence:** It's the site where you watch the portfolio get
built while you scroll it.

**Authored silence:** none.

## Score

| Beat | Device | Why |
|---|---|---|
| Hero | `parallax` (4 planes + pointer) | Depth around a live subject; copy rides at 1x |
| Work intro / FungEye | `flow` + light parallax | Quiet before the peak |
| Assembly | `pin` + signature | The frame holds while parts arrive |
| About | `reveal` | A wipe is a change of state: from work to the person |
| Expertise | `pan` | Lateral travel reads as breadth |
| Contact | `kinetic` + rise | The page stops moving and asks |

Signature move: **exploded-view assembly with live build lines**. Each project
card starts as a blueprint slot (dashed guides) with its plate, art, status tag
and metadata floating apart in depth; scroll bolts them together while a mono
build line counts SCAFFOLDING, WIRING, POLISHING, ASSEMBLED.
